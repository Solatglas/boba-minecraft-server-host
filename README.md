## 🔧 Troubleshooting Tips

If something does not work as expected, these quick checks solve most common problems.

- **The server will not start** – Make sure you have enough free memory. Close other applications and try again. If you are using a modpack, confirm that the modpack supports the Minecraft version you selected.
- **Friends cannot connect** – Double-check that you sent them the exact playit.gg address shown in the app. Ask them to copy and paste it rather than typing it by hand.
- **The server crashes after adding mods** – Remove the most recently added mod and restart. Mods sometimes conflict with each other or require a specific loader version.
- **The console shows errors about missing files** – Use the file explorer to confirm that your server folder was not moved or renamed. The app expects its files to stay in the same location.
- **Your world disappeared** – Open the backups tab and restore the most recent backup. This is exactly what the backup system is for.
